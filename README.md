## 🌟 Overview

**Coffee Shop 3D** is a modern frontend experience exploring interactive 3D product visualization for specialty coffee roasters. Users can inspect detailed 3D assets in real time, view customized flavor profiles, and experience dynamic spatial lighting and fluid animations.

---

## 🛠️ Tech Stack

- **3D Engine**: [Three.js](https://threejs.org/) (WebGL rendering, GLTF/GLB asset loading, ambient & directional lighting, orbital controls)
- **Tooling**: [Vite](https://vitejs.dev/) for fast HMR and optimized production bundles
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom luxury color palette and glassmorphism UI
- **Typography & Icons**: Inter / Google Fonts & Lucide Icons

---

## ✨ Key Features

- **Interactive 3D Product Canvas**: 360-degree interactive camera orbit, zoom, and smooth inertia dampening.
- **Micro-Interactions**: Hover states, smooth card reveals, and dynamic camera transitions responding to UI selections.
- **Responsive Layout**: Designed to adapt from desktop widescreen displays to tablet and mobile screens.
- **Optimized Asset Pipeline**: Compressed textures and geometry for fast initial load times.

## 🚀 Getting Started

### Installation
```bash
git clone https://github.com/Sciclox/coffee-shop-3d.git
cd coffee-shop-3d
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
